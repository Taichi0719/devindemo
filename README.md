# ユースフルGPT

ChatGPTとチャットできるWEBアプリケーション

![ユースフルGPT](logo.png)

## 概要

ユースフルGPTは、OpenAI ChatGPT APIを使用してブラウザ上で直接ChatGPTと会話できるWEBアプリケーションです。シンプルで美しいインターフェースと、ファイル添付機能を備えています。

## 特徴

- 🎨 **美しいUI**: ブルー〜ティールグラデーションの洗練されたデザイン
- 💬 **リアルタイムチャット**: ChatGPTとスムーズな会話体験
- 📎 **ファイル添付**: ドラッグ&ドロップでファイルを簡単添付
- ⚙️ **カスタマイズ可能**: システムプロンプトの設定でChatGPTの動作をカスタマイズ
- 🔒 **セキュア**: APIキーはローカルストレージに安全に保存
- 📱 **レスポンシブ**: デスクトップ・モバイル対応

## 使用方法

### 1. アプリケーションの起動

`index.html`ファイルをブラウザで開くだけで使用できます。ビルドプロセスは不要です。

```bash
# ローカルサーバーで起動する場合（推奨）
python -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

### 2. 初期設定

1. 右上の歯車アイコン（⚙️）をクリック
2. OpenAI APIキーを入力
   - [OpenAI APIキーを取得](https://platform.openai.com/api-keys)
3. システムプロンプト（任意）を設定
4. 「保存」をクリック

### 3. チャット開始

- メッセージ入力欄にテキストを入力
- 「送信」ボタンをクリックまたはEnterキーで送信
- ChatGPTからの返答を待つ

### 4. ファイル添付

#### ドラッグ&ドロップ
- ファイルをチャット画面にドラッグ&ドロップ

#### クリックして選択
- ファイル添付エリアをクリックしてファイル選択

#### 対応ファイル形式
- **テキストファイル**: `.txt`, `.md`, `.json`, `.csv`, `.js`, `.html`, `.css`
  - ファイル内容がメッセージに含まれます
- **画像ファイル**: `.png`, `.jpg`, `.gif`
  - ファイル情報が表示されます
- **その他**: バイナリファイル等
  - ファイル名と形式が表示されます

#### 制限事項
- 最大ファイルサイズ: 10MB
- 複数ファイル同時添付可能

## 技術仕様

### フロントエンド
- **React 18**: UIライブラリ
- **Babel**: JSXトランスパイル（ブラウザ内）
- **CSS3**: グラデーション、グラスモーフィズム効果
- **FileReader API**: ファイル読み取り

### API
- **OpenAI ChatGPT API**: GPT-3.5-turbo使用
- **ストリーミング非対応**: 一括レスポンス

### ストレージ
- **localStorage**: APIキー、システムプロンプトの保存

## セキュリティ

- APIキーはブラウザのlocalStorageに保存
- APIキーは外部に送信されません
- HTTPS推奨（本番環境）

## カスタマイズ

### システムプロンプト例

```
あなたは親切で知識豊富なアシスタントです。
日本語で丁寧に回答してください。
```

```
あなたはプログラミングの専門家です。
コードの説明は詳細に、実例を交えて説明してください。
```

### スタイルカスタマイズ

`index.html`内のCSSセクションを編集することで、色やレイアウトをカスタマイズできます。

## トラブルシューティング

### APIキーエラー
- OpenAI APIキーが正しく入力されているか確認
- APIキーに十分なクレジットがあるか確認

### ファイル添付エラー
- ファイルサイズが10MB以下か確認
- ブラウザがFileReader APIをサポートしているか確認

### 表示エラー
- ブラウザのJavaScriptが有効になっているか確認
- モダンブラウザ（Chrome, Firefox, Safari, Edge）を使用
